## 📌 Overview

**JuriConnect** is a full-stack legal networking platform designed to connect users with **verified advocates and document writers**.

The platform ensures trust and authenticity by allowing only **admin-approved professionals** to appear publicly, while users can securely register, send inquiries, verify accounts, and provide feedback.

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/your-username/JuriConnect.git
cd JuriConnect
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
EMAIL_USER=your_email
EMAIL_PASS=your_password
BREVO_SMTP_HOST=your_smtp_host
BREVO_SMTP_PORT=587
```

### 4. Run Application

```bash
npm start
```
